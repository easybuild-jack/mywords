# 2026-09-15

## 通读 MyWords 项目（理解性梳理，未改代码）

- 项目定位：Next.js 16 + React 19 的纯前端英语单词记忆应用，数据全存本地 IndexedDB（Dexie）+ localStorage（Zustand persist），无自建后端业务库。
- 路由：`/` 重定向到 `/learn`；页面有 learn / dictation / phonetics(+learn) / dictionary / books / errors / roots / grammar；Sidebar 中 `/phrases`、`/translate` 标记为「待开放」。
- 核心状态：`src/store/useWorkspaceStore.ts` 是唯一业务中枢（约 2000 行），管理书/单元/模式游标、循环次数、默写三连对、错词攻坚、音效与皮肤。`cursors` 为 learn/dictation/phonetic/error 四份独立存档。
- 持久化：`src/db/index.ts` Dexie v6（books / units / wordRecords / unitProgress / wordOverrides / aiWordCache）。单元进度唯一写入点是 `markUnitWordCompleted`，只有逐字敲完整词才记进度。
- 词库：`public/dicts/*.json`（basewords / CET_4_6 / kaoyan / essential4000 / it-words）+ `*.units.json` 语义单元目录，由 `src/core/dictionaryLoader.ts` 动态 fetch，运行时把 RawDictEntry 映射成 WordItem。
- 音节体系：`design/SYLLABLE_RULES.md` + `WORD_DATA_SPEC.md` 是数据生产规范；`src/lib/syllables.ts` 为运行时实现，`scripts/rebuild-*.mjs`、`check-syllables-by-phonetics.mjs` 为批量重建/校验工具。
- 外部同步：`/api/words/collect`（推入）→ `/api/words/pending`（消费）→ `ExternalSyncManager` 轮询入生错词本，存储走 Upstash Redis，缺配置时降级到 `data/pending_words.json`。
- 权限：`src/lib/permissions.ts` 硬编码作者 token `myword_jack`，只有作者能通过 `/api/dict/update-word` 回写官方词库 JSON。
- AI：`/api/ai/chat` 为纯代理（Key 由客户端提供，存 localStorage），`src/lib/aiWordCore.ts` 负责查词补全 + IndexedDB 缓存 + 分阶段生成例句/词根。
- 分支：当前在 `dev`，工作区有 3 个 grammar 组件未提交改动。
